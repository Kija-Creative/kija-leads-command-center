# Lead Command Center

For all website generation and frontend work, follow the repository
Design Intelligence system.

Read first:

- AGENTS.md
- docs/site-generation/SITE-DNA.md
- docs/site-generation/INDUSTRY-RULES.md
- docs/site-generation/DESIGN-PRINCIPLES.md
- docs/site-generation/REFERENCE-LIBRARIES.md

When available, use:

- .design-references/skynet-site-system
- .design-references/design-playbooks-skill

Do not treat component libraries as website templates.

Before building a generated prospect website:

1. classify the business
2. select an appropriate industry profile
3. select an appropriate archetype
4. generate Site DNA
5. compare DNA against recent sites
6. resolve excessive similarity
7. build from the approved DNA
8. validate the implementation against that DNA

Implement changes rather than merely suggesting them unless I
explicitly ask for analysis only.
